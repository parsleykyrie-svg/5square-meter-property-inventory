# 5square meter Product Context

Public context supporting the [5square meter Marketing Agents](https://github.com/parsleykyrie-svg/5square-meter-marketing-operations) workspace.

The linked workspace contains ten Claude Code specialists, ten slash commands and the context-sync script. Start there for content strategy, SEO research, copywriting, social content, campaign planning, analytics and tracking tasks.

## Contents

- Product purpose and audience definitions in `context/product/project_idea.md`.
- Marketing domain vocabulary in `context/product/business_logic.md`.
- Content topic map in `context/product/service_mapping.md`.
- Context synchronisation in `scripts/sync_product_context.sh`.

Internal architecture, payment and KYC details, CRM records and detailed user stories are not distributed here. Product capabilities and results must be confirmed before published use.

```sh
bash scripts/sync_product_context.sh /path/to/SDLC
```

Review context changes locally before committing them.
